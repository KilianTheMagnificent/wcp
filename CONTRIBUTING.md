# Contributing to wcp

Issues, bug reports, edge-case reproductions, and documentation feedback are welcome.

If a command produces an unexpected result or a workflow is unclear, please open an issue with:

- Your OS and Python version (`python3 --version`)
- Your `git --version` and `wcp version`
- The exact command sequence you ran in a small test repository
- The expected and actual output (using invented file names and values — never real credentials, private repository names, or personal paths)

## Pull requests

Andre directs development with AI coding assistants and accepts community feedback through GitHub issues. Outside pull requests are turned off because Andre cannot personally review outside code changes.

## Security

For a suspected security issue or isolation bypass, please use the private reporting process in [SECURITY.md](SECURITY.md) rather than opening a public issue.
